# AGENTS.md

## Project
Static flashcard app for learning Brazilian states. Vanilla HTML/CSS/JS, runs entirely in the browser. No build step, no server, no dependencies.

## Commands
- Open `index.html` in a browser to run. No dev server required.
- No package manager, no `npm install`, no build scripts.

## Conventions
- No frameworks or libraries. Use vanilla DOM APIs.
- All code runs client-side. No backend calls expected.
- Keep everything self-contained in the project root.
